# MmdRcpMid 使い方

概要
PC-98用音楽ファイル（.mmd、.rcp）をStandard MIDI File（.mid）またはRecomposer RCP形式（.rcp）に変換するツールです。変換にはrcpcv.dllが必要です（.mid出力時のみ）。

準備
- mmdrcpmid.exeと同じフォルダにrcpcv.dllを置いてください
- .rcpファイルを.midに変換する場合のみrcpcv.dllが必要です
- .mmdファイルの変換は.midと.rcp両方に対応しています

基本的な使い方
- .mmd・.rcp・.midファイルをウィンドウ内にドラッグ＆ドロップすると変換が始まります
- 複数ファイルを一度にドロップできます
- 変換結果はウィンドウ内のログエリアに表示されます。Ctrl+Cでコピーできます

オプション
「出力フォルダ指定」チェックボックス
- チェックを入れると変換後のファイルを指定したフォルダに保存できます
- チェックなしの場合は元ファイルと同じフォルダに保存されます
- 「...」ボタンでフォルダを選択できます

「出力形式」ドロップダウン
- Standard MIDI File (.mid)：.midファイルとして出力します（rcpcv.dll必要）
- Recomposer RCP (.rcp)：.rcpファイルとして出力します（rcpcv.dll不要）

注意事項
変換中にウィンドウを閉じようとするとキャンセルの確認が出ます。
すでに同じ形式のファイルをドロップするとその旨がログに表示されスキップされます。
同名ファイルが出力先に存在する場合は上書きされます。
